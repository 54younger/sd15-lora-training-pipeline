## Evidence lineage and inference-ready definition

A reproducible delivery should trace dataset/file IDs through frozen prepared.json → training-input.json → training-result/checkpoint → evaluation.json/html → PUBLISH model record. An inference-ready artifact binds adapter.safetensors, adapter SHA-256, base revision/fingerprint, trigger token, inference config and evaluation report; it is neither automatically READY nor online serving. Default business quality is uncertified, and downloading UNVERIFIED requires explicit opt-in.
